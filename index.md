Reminders is a small desktop application for Windows and Linux. It keeps your reminders, such as people's
birthdays or one-time events, and shows upcoming ones as a post-it note on your desktop several days before
the date.

## Features

- Birthday reminders with configurable notice and greeting template
- One-time reminders with a configurable number of days of notice
- Overview with search, edit and delete
- Import and export of reminders to a plain text file
- Optional backup and synchronization of reminders through your own Google Drive
- Czech and English user interface

## Download

[Download Reminders (zip, latest version)](https://github.com/linhartJ/reminders-desktop/releases/latest/download/reminders.zip)

Requires Java 25. Installation guides are inside the archive in the `install` folder.

## Google Drive

When you choose to log in with Google, Reminders only accesses files and folders it created itself in your
Google Drive, to store backups and the synchronization file of your reminders. See the
[privacy policy](privacy) for details.
